# External Reference × SAOKO
Interactive design presentation for the SAOKO stand in Geneva.

Stand and website design: [External Reference](https://externalreference.com/).
Graphic identity: CONJUNTO STUDIO. Brand assets belong to their respective owners.

This is a static, responsive presentation. Publish the main branch root using GitHub Pages.
Votes are stored centrally in the SAOKO poll service. Each page opening gets a new in-memory anonymous voting key.
One confirmed choice per page opening, with cumulative vote counts and percentages revealed after confirmation.
Reopening the page allows another vote; totals represent votes, not unique people.
No sample votes are imported from the offline beta.

Architectural intro proportions follow the supplied 3250 mm frontage reference.
Dish photos keep their intrinsic proportions. Print artwork is scalable SVG.
